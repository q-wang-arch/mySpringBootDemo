## 1. 通用约定

### 1.1 基础信息

| 项目 | 值 |
|------|-----|
| Base URL | `http://localhost:8080/api` |
| 数据格式 | application/json |
| 字符编码 | UTF-8 |
| 鉴权方式 | Bearer Token（Header: `Authorization: Bearer <token>`） |

### 1.2 统一响应结构

```json
{
  "code": 200,
  "message": "success",
  "data": { },
  "timestamp": "2026-09-15T10:00:00"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 200=成功，400=参数错误，500=服务器异常 |
| message | String | 结果描述 |
| data | Object | 业务数据 |
| timestamp | String | 响应时间 |

## 2. 数据接入接口

### 2.1 推送贷后数据

**POST** `/api/agent/ingest`

接收源头系统推送的标准化贷后数据，触发智能体分析流程。

**请求体**：
```json
{
  "borrowerId": "BR20260001",
  "borrowerName": "张三",
  "loanId": "LN20260001",
  "reportPeriod": "2026-09",
  "loanInfo": {
    "loanAmount": 500000,
    "loanBalance": 320000,
    "loanType": "经营贷",
    "loanStartDate": "2026-01-15",
    "loanEndDate": "2027-01-14",
    "interestRate": 5.85
  },
  "repaymentInfo": {
    "totalTerms": 12,
    "completedTerms": 8,
    "ontimeCount": 7,
    "overdueCount": 1,
    "maxOverdueDays": 5,
    "currentOverdueDays": 0
  },
  "financialInfo": {
    "monthlyIncome": 35000,
    "monthlyIncomeChange": -0.08,
    "debtRatio": 0.42,
    "debtRatioChange": 0.05,
    "cashFlowStatus": "正常"
  },
  "riskSignals": {
    "multiLending": false,
    "guaranteeChainAbnormal": false,
    "litigationRecord": false,
    "businessAbnormal": false,
    "assetTransfer": false
  },
  "externalData": {
    "creditScore": 680,
    "creditScoreChange": -15,
    "courtFilingCount": 0,
    "taxArrears": false
  }
}
```

**响应**：
```json
{
  "code": 200,
  "message": "数据已接收，分析任务已创建",
  "data": {
    "taskId": "TASK20260915001",
    "status": "PENDING"
  }
}
```

### 2.2 批量导入数据

**POST** `/api/agent/ingest/batch`

**请求**：`multipart/form-data`，上传 CSV/Excel 文件

**响应**：
```json
{
  "code": 200,
  "message": "批量导入完成",
  "data": {
    "totalCount": 100,
    "successCount": 95,
    "failedCount": 5,
    "taskIds": ["TASK20260915001", "TASK20260915002", "..."]
  }
}
```

## 5. 预警接口

### 5.1 查询预警列表

**GET** `/api/alert/list?status=&level=&page=1&size=20`

**响应**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 10,
    "page": 1,
    "size": 20,
    "records": [
      {
        "alertId": "ALT20260915001",
        "taskId": "TASK20260915001",
        "borrowerId": "BR20260001",
        "borrowerName": "张三",
        "ruleId": "RULE-006",
        "ruleName": "收入下降",
        "level": "MEDIUM",
        "status": "TRIGGERED",
        "createTime": "2026-09-15T10:00:02"
      }
    ]
  }
}
```

### 5.2 处置预警

**POST** `/api/alert/{alertId}/handle`

**请求体**：
```json
{
  "handler": "李四",
  "action": "PROCESSING",
  "comment": "已联系借款人核实，收入下降系季节性因素"
}
```

**响应**：
```json
{
  "code": 200,
  "message": "预警处置已记录",
  "data": {
    "alertId": "ALT20260915001",
    "status": "PROCESSING"
  }
}
```

### 5.3 关闭预警

**POST** `/api/alert/{alertId}/close`

**请求体**：
```json
{
  "handler": "李四",
  "result": "已核实，风险可控",
  "approver": "王五"
}
```

## 7. 状态码汇总

| HTTP Code | 业务含义 |
|-----------|---------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未认证/Token失效 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 409 | 数据重复（如同期报告已存在） |
| 500 | 服务器内部异常 |
| 503 | 智能体引擎繁忙，稍后重试 |
