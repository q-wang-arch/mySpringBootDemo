### 2.2 智能体状态机

```
PENDING ──> RUNNING ──> COMPLETED
               │
               ├──> FAILED (可重试)
               │
               └──> MANUAL_REVIEW (需人工介入)
```

| 状态 | 说明 |
|------|------|
| PENDING | 等待执行 |
| RUNNING | 正在执行分析流程 |
| COMPLETED | 全部分析步骤完成 |
| FAILED | 执行失败（可重试） |
| MANUAL_REVIEW | 需人工介入处理 |

### 2.3 智能体接口定义

```java
/**
 * 智能体步骤接口
 */
public interface AgentStep {
    /** 步骤名称 */
    String getStepName();
    
    /** 执行步骤 */
    StepResult execute(AnalysisContext context);
    
    /** 是否可跳过 */
    default boolean canSkip(AnalysisContext context) { return false; }
    
    /** 异常处理策略 */
    default StepFailureStrategy getFailureStrategy() { 
        return StepFailureStrategy.RETRY_3_TIMES; 
    }
}

/**
 * 分析上下文（在步骤间传递）
 */
public class AnalysisContext {
    private String taskId;              // 任务ID
    private BorrowerData borrowerData;  // 借款人数据
    private RepaymentAnalysis repaymentAnalysis;
    private FinancialAnalysis financialAnalysis;
    private RiskSignalAnalysis riskSignalAnalysis;
    private RiskScore riskScore;        // 风险评分与评级
    private String reportContent;       // 生成的报告
    private List<AlertInfo> alerts;     // 触发的预警
}

/**
 * 步骤执行结果
 */
public class StepResult {
    private boolean success;
    private String message;
    private Map<String, Object> data;
}
```

## 3. 分析引擎设计

### 3.1 还款行为分析 (RepaymentAnalyzer)

| 指标 | 计算方式 | 权重 |
|------|---------|------|
| 准时率 | ontimeCount / completedTerms | 30% |
| 逾期频率 | overdueCount / completedTerms | 25% |
| 最大逾期天数 | maxOverdueDays | 20% |
| 当前逾期天数 | currentOverdueDays | 25% |

### 3.2 财务状况分析 (FinancialAnalyzer)

| 指标 | 计算方式 | 权重 |
|------|---------|------|
| 收入变化率 | monthlyIncomeChange | 30% |
| 负债率 | debtRatio (>0.5 为高风险) | 35% |
| 负债率变化 | debtRatioChange | 20% |
| 现金流状况 | cashFlowStatus | 15% |

### 3.3 风险信号分析 (RiskSignalAnalyzer)

| 信号 | 判定条件 | 扣分 |
|------|---------|------|
| 多头借贷 | multiLending = true | -15 |
| 担保链异常 | guaranteeChainAbnormal = true | -10 |
| 诉讼记录 | litigationRecord = true | -10 |
| 经营异常 | businessAbnormal = true | -10 |
| 资产转移 | assetTransfer = true | -15 |

### 3.4 评分评级计算 (ScoringEngine)

**评分公式**：

```
风险评分 = 还款行为得分 × 0.35 + 财务状况得分 × 0.30 + 风险信号扣分 + 外部信用得分 × 0.35
```

- 各维度得分归一化到 0-100
- 风险信号扣分为直接扣减
- 最终评分范围：0-100

**评级映射**：

| 评分范围 | 评级 | 说明 |
|---------|------|------|
| 85-100 | A | 优质，风险极低 |
| 70-84 | B | 良好，风险较低 |
| 55-69 | C | 关注，风险一般 |
| 40-54 | D | 次级，风险较高 |
| 0-39 | E | 损失，风险极高 |

## 4. 报告结构设计

### 4.1 报告内容结构

```
贷后分析报告
│
├── 一、借款人概况
│   ├── 借款人基本信息
│   ├── 贷款合同信息
│   └── 当前贷款余额
│
├── 二、还款行为分析
│   ├── 还款记录概览（期数/准时次数/逾期次数）
│   ├── 逾期分析（最大逾期/当前逾期）
│   └── 还款行为评分
│
├── 三、财务状况分析
│   ├── 收入变化趋势
│   ├── 负债率分析
│   ├── 现金流状况
│   └── 财务状况评分
│
├── 四、风险信号识别
│   ├── 多头借贷
│   ├── 担保链异常
│   ├── 诉讼记录
│   ├── 经营异常
│   ├── 资产转移
│   └── 外部信用变化
│
├── 五、风险评级
│   ├── 综合评分
│   ├── 风险评级（A/B/C/D/E）
│   └── 评级变化趋势
│
├── 六、结论与建议
│   ├── 总体评价
│   ├── 风险提示
│   └── 建议措施
│       ├── A/B: 常规监控
│       ├── C: 加强监控频率
│       ├── D: 约谈/要求增信
│       └── E: 保全措施/法律追偿
│
└── 报告生成信息
    ├── 报告ID
    ├── 生成时间
    ├── 分析任务ID
    └── 智能体版本
```

## 5. 预警规则设计

### 5.1 预警规则配置

| 规则ID | 规则名称 | 触发条件 | 预警级别 | 通知方式 |
|--------|---------|---------|---------|---------|
| RULE-001 | 评级下降 | 评级较上期下降 >= 2 级 | 高 | 飞书+邮件 |
| RULE-002 | 评级为 D | 当前评级 = D | 中 | 飞书 |
| RULE-003 | 评级为 E | 当前评级 = E | 紧急 | 飞书+邮件+短信 |
| RULE-004 | 逾期超限 | currentOverdueDays > 30 | 高 | 飞书+邮件 |
| RULE-005 | 多头借贷 | multiLending = true | 中 | 飞书 |
| RULE-006 | 收入下降 | monthlyIncomeChange < -0.2 | 中 | 飞书 |
| RULE-007 | 负债率过高 | debtRatio > 0.6 | 中 | 飞书 |

### 5.2 预警工单生命周期

```
TRIGGERED ──> ASSIGNED ──> PROCESSING ──> COMPLETED
                                │
                                └──> ESCALATED (升级处理)
```
